# rgctl v0.4.25

Universe is now the only dashboard UI (`--with-universe` + `serve --open`), with Architecture district drill-down, Migration and Taint rooms, corrected Kantra docs, and restored DCO enforcement in CI.

```bash
rgctl --version   # 0.4.25

# Export the universe bundle, then open it
rgctl discover . --with-cfg --with-universe
rgctl serve --open
```

## Highlights

### Universe dashboard is the only UI (#145, #61)

Completes the `#61` flag swap: the v2 universe shell is the sole browser UI.

- **`rgctl discover --with-universe`** is the only discover flag that exports the dashboard bundle (writes `.rgctl/dashboard/` with `manifest.mode: "universe"`).
- **`rgctl serve --open`** always serves that universe shell (re-extracts embedded v2 static assets when an older on-disk bundle is present).
- **Removed:** `--with-dashboard` and `serve --dashboard-only`. Scripts and docs that still pass those flags must switch to `--with-universe` / `serve --open`.
- **`serve` stays serve-only** (no auto full pipeline); prepare artifacts with `discover` (or `discover --full`) first.
- Finishes the dashboard v2 shell work: URL focus, language tiers, harness parity, and the rooms/lenses layout shipping from `dashboard/dist-v2`.

### Architecture Universe drill-down & rooms (#145 follow-ups)

Hardens the 3D Architecture room and expands the room set shipped with the universe bundle:

- **District expand / drill-down:** double-click a district to open it; package membership is exported so expand is not a silent no-op; progress reporting while a district opens; drift paused inside a district.
- **Pickable members:** click a member to open it in Understand; member naming vs opening split; level links and breadcrumb navigation.
- **District finder:** unclipped finder so operators can answer “which of these boxes is that one?” on dense maps.
- **One graph lens:** retires separate `code` / `cfgpdg` lenses; keeps their framings as controls. The CFG lens is named **CFG** (not “spine”).
- **Source reader:** shared reader with remembered scroll/span across lens switches; open on the subject and follow block clicks.
- **New rooms:** **Migration** and **Taint** rooms alongside Architecture / Understand / Repo.
- Default landing at `/` is **Architecture**.

### Kantra docs corrections (#162)

Updates `docs/design/kantra-integration-exploration.md` and `docs/user-guide.md` for enrichment, source-cache, pipeline order, and cross-references so Kantra discover / Migration Rules docs match the shipped CLI.

### CI: DCO sign-off restored & split workflows synced (#166)

- Dedicated **`dco`** job in `.github/workflows/ci-lint.yml` checks all non-merge commits in `BASE_SHA..HEAD_SHA` for a valid `Signed-off-by: Name <email>` trailer.
- `scripts/check-no-ai-commit-trailers.py` gains `--dco-only` / `--require-dco`; `scripts/preflight-pr.sh` enforces `--require-dco`.
- Split CI workflows (`ci-lint.yml`, `ci.yml`, `ci-qe.yml`, `ci-perf.yml`) re-synced onto `main`.

## Breaking changes

| Removed / changed | Migration |
|-------------------|-----------|
| `discover --with-dashboard` | Use `discover --with-universe` |
| `serve --dashboard-only` | Use `serve --open` (or `serve` without `--query-only`) |
| Older `.rgctl/dashboard/` bundles without `manifest.mode: "universe"` | Re-run `discover --with-universe`; `serve --open` re-extracts the v2 shell when needed |
