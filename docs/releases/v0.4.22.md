# rgctl v0.4.22

Enterprise & mainframe language expansion (66 languages total), OSV vulnerability call-site linking via parked relations, Dashboard v2 with the 3D Architecture Universe room, Fast-Leiden community labeling fidelity, alias-aware program slicing, and PR-first release automation.

```bash
rgctl --version   # 0.4.22

# Discover mainframe / enterprise polyglot repos (COBOL + PL/I + JCL)
rgctl discover . -l cobol,pli,jcl -v

# Link OSV advisories to exact in-repo caller symbols, file:line sites, and upstream paths
rgctl -f json vuln analyze --osv-dir ./osv --include-jars lib

# Alias-aware program slicing without specifying --function (auto-resolved from file:line)
rgctl -f json slice src/OrderService.java --line 42 --variable order --with-alias
```

## Highlights

### Legacy, mainframe & enterprise migration languages (#143, #144)

Adds **8 new Tier-2 language plugins** (bringing total supported languages to **66**):

- **COBOL** (`rgctl-lang-cobol` — `.cbl`, `.cob`, `.cpy`): custom line-oriented structural extractor for `PROGRAM-ID`, paragraphs and sections, `01` data items, `COPY` books, `PERFORM`, `CALL`, and `EXEC CICS LINK` / `XCTL`.
- **PL/I** (`rgctl-lang-pli` — `.pli`, `.pl1`, `.inc`): structural extractor for `PACKAGE`, nested `PROC` / `PROCEDURE` scopes, `DCL` / `DECLARE 1` structures, `%INCLUDE`, `CALL`, `FETCH`, and `EXEC CICS`.
- **JCL** (`rgctl-lang-jcl` — `.jcl`, `.proc`, `.cntl`): batch card/statement extractor for `JOB`, `PROC`, `EXEC PGM=` / `EXEC PROC=`, `INCLUDE MEMBER`, non-system `DD DSN=` dataset references, and DB2 `IKJEFT01` (`SYSTSIN RUN PROGRAM(...)`) so batch step dependencies link directly to COBOL and PL/I programs.
- **Apex / Salesforce** (`rgctl-lang-apex` — `.cls`, `.trigger`, `.apex`): classes, interfaces, enums, triggers, methods, and constructors via `tree-sitter-sfapex`.
- **Pascal / Delphi** (`rgctl-lang-pascal` — `.pas`, `.dpr`, `.dpk`, `.lpr`): procedures, functions, classes, interfaces, types, and `uses` clauses (excluding `.pp` to preserve Puppet disambiguation).
- **Perl** (`rgctl-lang-perl` — `.pl`, `.pm`, `.t`): subroutines, methods, and `use` / `require` imports.
- **Ada** (`rgctl-lang-ada` — `.adb`, `.ads`, `.ada`): subprogram declarations/bodies, full/task/protected types, and `with` clauses.
- **MATLAB / Octave** (`rgctl-lang-matlab` — `.matlab`, `.m`): functions and `classdef` classes, paired with header/syntax content sniffing in `rgctl-registry` to disambiguate `.m` files between MATLAB and Objective-C.

### OSV vulnerability call-site linking via parked relations (#150, #151)

- `rgctl vuln analyze` now inspects `.rgctl/parked_relations.bin` in addition to resolved in-graph nodes when matching OSV affected symbols and sink hints.
- External third-party calls recorded during `discover` (such as `ObjectMapper.readValue` in `jackson-databind`) now populate `call_sites` (`caller`, `target_method`, `file`, `line`) and trace upstream intra-repo `call_paths` back to entry points (e.g., MDB listeners or REST controllers).

### Dashboard v2 & 3D Architecture Universe (#131, #135, #137, #139)

- **Additive v2 dashboard bundle (`dashboard/dist-v2`)**: rooms × lenses architecture with URL-addressable state (`?room=...&lens=...&focus=...`), shipping **Spine** (bi-directionally bound source + CFG) and **CFG-PDG** (`?lens=cfgpdg`) lenses at less than half the v1 gzipped footprint.
- **Architecture Universe room (`--with-universe`)**: 3D WebGL view rendering L0 namespace volumes over L1 package solids with Fast-Leiden communities as an interactive color and collapse overlay.

### Fast-Leiden community fidelity & Louvain removal (#138, #139)

- Standardized community detection exclusively on **Fast-Leiden**, removing legacy Louvain references across analysis, migration planning, and documentation.
- Hardened community auto-labeling (`community_label.rs`) and package plurality voting in `rgctl-analysis` and `rgctl-dashboard`:
  - Canonical `package_label` derivation and deterministic tie-breaking.
  - `File` nodes no longer dilute code-symbol community plurality votes.
  - Improved camelCase splitting and stopword filtering; tuned default hub-stripping threshold (`DEFAULT_HUB_SIGMA_K = 4.0`).

### Program slicing & Hybrid CPG ergonomics (`ddf55db0`)

- `rgctl slice` and `rgctl cpg slice` now expose `--with-alias` on the CLI to expand slice criteria across intra-procedural may-alias copies and field bases.
- `rgctl cpg flows` (like `rgctl slice`) now makes `--function` optional and automatically resolves the innermost enclosing function from `file:line`.

### CI, local preflight gates & automated release workflow (#147, #152, #153)

- Added `./scripts/preflight-pr.sh` (`--quick`, `--lint`, `--qe`, `--perf`, `--full`) to mirror CI lint, clippy, AST coverage (`RGCTL_AST_COVERAGE_STRICT=1`), and release test gates locally.
- Added PR-first release automation (`.github/workflows/release-pr.yml`, `./scripts/bump-version.sh <auto|patch|minor|major> --pr`) and automatic `vX.Y.Z` tagging + binary publishing on merge to `main` in `.github/workflows/release.yml`.
- Completed repository migration cleanup (`rgctl/rgctl` canonical links and split of `rgctl/rgctl-website`).
