# rgctl v0.4.27

Kantra/Konveyor static analysis reaches full AST & call-site precision (`java.referenced` JR1–JR7, `java.dependency` semver bounds, `builtin.xml` XPath, `RBKC` v2 rule metadata), the Universe **Static rules** room surfaces confidence, effort, blast radius, sources, links, and skipped rules, and both cold discover (`QueryLanguagePlugin` lazy compilation) and CI pre-flight (`preflight-pr.sh`) are significantly faster and lighter on disk/RSS.

```bash
rgctl --version   # 0.4.27

# Full profile: CFG + Universe + harmonic + taint + Kantra + semantic
rgctl discover . --full
rgctl serve --open   # Architecture + Static rules (+ Migration / Taint / …)
```

## Highlights

### Kantra `java.referenced` AST & call-site precision — JR1–JR7 (#177, #178)

Closes all seven `java.referenced` accuracy gaps between `rgctl` and Konveyor `kantra` / JDT.LS:

- **JR1 — Transitive `INHERITANCE` & external ancestors:** Iterative BFS over `EXTENDS` / `IMPLEMENTS` edges plus `extends_fqn` / `implements_fqns` seeds matches classes implementing or extending a target type across multi-hop hierarchies.
- **JR2 — `FIELD`, `VARIABLE_DECLARATION`, `RETURN_TYPE`, `METHOD`, `THROWS`, `TYPE`:** Import-aware FQN enrichment (`return_type_fqn`, `param_type_fqns`, `throws_fqns`, `field_type_fqn:<name>`) across class fields, method and overloaded constructor signatures (disambiguated `.<init>` keys and deterministic node IDs), `throws` clauses, implicit `java.lang.*` types, and method-local variable declarations.
- **JR3 — `PACKAGE` prefix matching & call sites:** Matches `import` prefixes, external `type_references`, and `to_qualified_hint` call sites without cross-package simple-name false positives or matching a file's own `package` / `Class` declaration; excludes `/src/test/` test sources from `java.referenced` violations to match Konveyor's main-source scope.
- **JR4 — `CONSTRUCTOR_CALL` (`new Type(...)`):** Java `object_creation_expression` emits `RelationType::Instantiates` with exact `call_site_line`/`column`, deduplicating stub-node edges.
- **JR5 — `METHOD_CALL` receiver, chained calls & guarded wildcard import resolution:** Intra-procedural receiver-type map (fields, parameters, local variables, cast expressions `((Type) x).m()`, and chained invocations like `req.getSession().setAttribute(...)`) combined with `FileTypeContext`-guarded wildcard import (`import pkg.*;`) expansion that never overrides explicit single-type imports, `java.lang.*` types, known JDK packages, or in-repo classes (and ignores `<external>` stub nodes when indexing in-repo classes).
- **JR6 — Kantra glob/regex normalization, composite `and:` chains & structured `annotated` (`elements` & `type`):** Normalizes Konveyor glob `*` (including leading `*`, group trailing `(A|B)*`, and escaped `\.` before `*`) and anchors bare type patterns on identifier boundaries; supports Konveyor condition-chaining metadata (`as`, `from`, `ignore`, `condition`, boolean `not: true`) and project-level `and:` conjunction semantics; extracts structured annotation attributes (`@Target(name = "val")`) and evaluates element key/value regex filters.
- **JR7 — Call-site line precision (`parked_relations.bin`), tag-rule chaining & confidence:** Persists external/unresolved `Calls` and `Instantiates` relations to `.rgctl/parked_relations.bin` so `CONSTRUCTOR_CALL` and `METHOD_CALL` report exact call-site lines rather than enclosing method headers; suppresses tag-only rules (`is_tag_only()`) from emitted violations while propagating matched tags to downstream `builtin.hasTags` rules; tags violations with `confidence` (`"high"` AST/graph/call-site vs `"low"` lexical fallback) and `matched_location`.

### Konveyor rules engine: `java.dependency`, `builtin.xml` XPath, `RBKC` v2 & duplicate `ruleID` merge (#178)

- **`java.dependency` / `go.dependency`:** Evaluates Maven/semver version bounds (`lowerbound`, `upperbound`, `nameregex`), normalizes dot vs. colon coordinates (including multi-dot `artifactId`s such as `jakarta.ws.rs:jakarta.ws.rs-api`), and includes `pom.xml` / `build.gradle` manifests when `--languages java` is active.
- **`builtin.xml` XPath & `builtin.json`:** Supports multi-axis XPath expressions (`//tag[@attr='v']`, `text()`, `local-name()`, `namespace-uri()`, descendant `//`, and `|` unions), records unsupported XPath predicates in `skipped_rules`, and collects `WEB-INF/*.xml` descriptors during `discover --with-kantra`.
- **`RBKC` v2 catalog & duplicate `ruleID` union:** Preserves `description`, `links[]` (`title`, `url`), and `tag[]` in the compiled catalog (`RBKC` v2); soft-merges duplicate `ruleID`s across multi-target rulesets; suppresses tag-only rules (`is_tag_only()`) from incident counts and records them in `skipped_rules`.

### Universe Static rules room & Kantra bundle enrichment (#179)

Upgrades the Universe **Static rules** room (`dashboard/src/v2/rooms/Rules.tsx` + `kantra_index.json` / per-file shards):

- **Filters & header controls:** Adds **Source** technology filter (`konveyor.io/source`), **High confidence only** toggle, and a clickable **`{N} skipped`** header chip that expands the skipped-rules table (`Rule` / `Reason`).
- **Violations table:** Adds per-row **Effort**, **Confidence** (`high` / `low` chip), and **Blast** (`blast_radius_score`) columns alongside `Rule`, `Line`, `Category`, and `Symbol`.
- **Violation detail panel:** Shows rule `description`, `message`, `effort`, `targets`, `sources` chips, clickable external documentation `links[]`, `matched_location` in the subtitle (`line N · CONSTRUCTOR_CALL`), and graph enrichment metrics (`blast radius`, `impact zone`, `community`, `pagerank`).

### Universe dashboard export (`--with-universe`) & cold-discover performance (#174, #175, #177, #181)

- **Universe dashboard export overhaul (#181):** Cuts cold `save_dashboard` wall time by **6.9×** on 134k-function Java repos (`15.05 s → 2.17 s` on `metasfresh`) and **4.4×** on `discourse` (`0.65 s → 0.15 s`), and warm no-op export to **`~106 µs`**:
  - Replaces full-file `fs::read("graph.snapshot.bin")` (`106 MB`) and eager `fs::read("kantra_findings.json")` (`31 MB`) before the dashboard fingerprint check with `O(1)` `SnapshotNodeStore::file_len()`, `File::metadata().len()`, and in-memory `KantraFindings` handoff.
  - Shares a single `Arc<SnapshotNodeStore>` and `Arc<HashMap<Uuid, u32>>` index across `export_metagraph` and `export_blast_bundle_with_graph`, and reuses `analysis_index.bin` via `function_meta_map_with_index`.
  - Eliminates the per-function `slice/<uuid>.json` file storm on large repos (`> 5,000` functions) in favor of `cfg.pack.bin` + `cfg.idx.bin` range reads (`slices_export_mode: "archive_only"`) and skips rewriting unchanged `kantra/*.json` shards via `.kantra_export.fingerprint`.
- **Lazy Tier-2 tree-sitter query compilation:** `QueryLanguagePlugin` validates capture names at construction and compiles tree-sitter `.scm` queries lazily via `OnceLock` on first `extract_all`, eliminating ~300 ms CPU and ~119 MB RSS of eager compilation across unused Tier-2 grammars.
- **Indexed `build_eval_graph` & gated call-site loading:** Replaces $2 \times |E|$ `ColdMetadataDb::get_node()` bincode deserializations with an $O(1)$ `Uuid -> usize` index lookup and gates `CALLS`/`INSTANTIATES` + `parked_relations.bin` loading on `engine.needs_call_sites()`.
- **Pre-flight & CI disk/time overhaul (#174, #175):** Parallel test execution in `scripts/preflight-pr.sh`, unified `rgctl-plugin-api` crate features to eliminate duplicate 380-crate compiles in CI, normalized `build.rs` `rerun-if-changed` paths, automatic post-run artifact cleanup, and direct CI workflow delegation to `preflight-pr.sh`.
