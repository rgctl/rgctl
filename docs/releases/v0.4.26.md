# rgctl v0.4.26

Universe gains a **Static rules** room for Kantra triage, `discover --full` becomes a deeper default profile (taint + Kantra + harmonic), and ScarfBench-driven skill / Kantra / Java DI / CLI ergonomics land for agent workflows.

```bash
rgctl --version   # 0.4.26

# Full profile: CFG + Universe + harmonic + taint + Kantra + semantic
rgctl discover . --full
rgctl serve --open   # Architecture + Static rules (+ Migration / Taint / …)
```

## Highlights

### Universe Static rules room (#171)

Ports the v1 Kantra triage UI into Universe as a dedicated **Static rules** room (`rules`):

- **Index-first load:** `kantra_index.json` + per-file shards on demand; category + Konveyor target filters, file search/pagination, violations table, rule detail, and source snippets.
- **Missing vs stale vs empty:** session `/api/status` `kantra_findings` distinguishes “no export”, “findings present but bundle stale”, and “zero violations”.
- **`dist-v2` rebuilt;** docs point at Static rules (not Migration Rules).

### `--full` includes taint + Kantra (+ harmonic) (#172)

`rgctl discover --full` deep stage always enables `--with-taint` and `--with-kantra` alongside CFG, Universe, and harmonic, then runs semantic index. Secret scanning, git churn, SCIP, and migration roadmap export remain opt-in. Warm deep skips require taint + Kantra artifacts; dashboard export rewrites when `index.html` is missing even if the manifest fingerprint matches.

### Architecture room: stable outgoing coupling + UX (#168, #169)

- **Line2 outgoing edges** stop flicker on segments leaving an open district; viewport-aware thickness; `BUDGET_KIB_V2` → 330 KiB.
- **One surface, one mode:** back arrow while drilled in; click selects, `</>` opens code; picks prefer solids through namespace volumes; press pauses drift.

### Agent skills & migration workflows (#170, #104, #105)

ScarfBench-driven overhaul of `rgctl` / `rgctl-migrate` skills: mandatory `.rgctl/` Step 0, first-line `rgctl -f json` for all tasks, continuous sync via `serve --watch` / `update`, three-track migrate skill (framework/runtime, API/package, Strangler-Fig), explicit Kantra target matrix, inventory `.counts` fix (#104), and `cargo:rerun-if-changed` for migrate/vuln skills.

### Kantra target metadata, `rules run` / `findings` / `targets` (#170)

- Violations and rule nodes carry `targets` / `sources` / `effort`.
- `rgctl rules run` can use the embedded catalog without a rules dir; token-compact `-f json`.
- `rgctl rules findings` filters by target/source/category/file; `rules targets` lists catalog labels + hit counts.

### Java field-level annotations & DI provenance (#170)

Single-pass annotated field `Variable` extraction; `find --annotation` resolves fields without `--with-cfg`; `@ConfigProperty` in DI frameworks; `Injects` edges record the triggering annotation in `call_context`.

### Incremental update hygiene & query CLI ergonomics (#104, #105, #170)

Snapshot-only `update` / `serve --watch` (no multi-MB `graph.json`); auto-append `.rgctl/` to `.git/info/exclude`; `inventory --limit` / `--prefix`; `blast-radius --summary`.

## Breaking changes

| Changed | Migration |
|---------|-----------|
| `discover --full` now runs discover-time taint + Kantra (higher wall / RSS) | Use bare `discover` + selective `--with-*` for a lighter path; pass `--with-security` / `--with-git` / `--scip` / `--export-migration-hints` alongside `--full` when needed |
